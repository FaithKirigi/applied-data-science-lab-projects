# Project 7: A/B Testing at WorldQuant University  

## 🔹 Problem  
Organizations often introduce new features or experiences without knowing whether they will meaningfully improve user behaviour.  
The goal of this project was to **design and evaluate an A/B test** to determine whether a change in the WorldQuant University learning experience influenced student engagement.  

---

## 🔹 Approach  

### Lesson 1: Building the Data Foundation  
- Designed a system for collecting and storing experimental data.  
- Created a database structure to record participant information, group assignments, and user actions.  
- Used Python to connect to the database and retrieve experimental observations.  

### Lesson 2: Developing an API  
- Built an API to manage communication between the experiment and the database.  
- Created endpoints for assigning participants to experimental groups and recording their interactions.  
- Validated incoming data before storing it for analysis.  

### Lesson 3: Designing the A/B Test  
- Divided participants into **control and treatment groups**.  
- Defined the experimental outcome and the user behaviour to be measured.  
- Considered random assignment, sample size, and potential sources of bias when designing the experiment.  

### Lesson 4: Statistical Hypothesis Testing  
- Compared engagement outcomes between the control and treatment groups.  
- Formulated null and alternative hypotheses for the experiment.  
- Applied a **chi-square test** to determine whether the observed relationship between group assignment and user behaviour was statistically significant.  

---

## 🔹 Results  
- Developed an end-to-end system for assigning participants, collecting observations, and evaluating an online experiment.  
- Compared engagement rates between the control and treatment groups.  
- Used statistical hypothesis testing to determine whether the observed difference could be attributed to the experimental change rather than random variation.  
- Demonstrated the importance of combining experimental design, data engineering, and statistical analysis when making product decisions.
