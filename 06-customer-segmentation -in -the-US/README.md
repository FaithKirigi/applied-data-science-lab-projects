# Project 6: Customer Segmentation in the US  

## 🔹 Problem  
Understanding the different financial profiles within a population can help financial institutions design more relevant products and improve customer targeting.  
The goal of this project was to **segment US households into groups based on their financial characteristics**, using unsupervised machine learning techniques to identify patterns in income, assets, debt, and access to credit.  

---

## 🔹 Approach  

### Lesson 1: Exploring Consumer Finance Data  
- Worked with household financial data from the **Survey of Consumer Finances**.  
- Cleaned and prepared demographic and financial variables using Python and Pandas.  
- Explored the distribution of income, assets, debt, and other household characteristics.  

### Lesson 2: K-Means Clustering  
- Selected relevant financial features for customer segmentation.  
- Standardized numerical features to ensure they contributed equally to the model.  
- Applied the **K-Means clustering algorithm** to group households with similar financial profiles.  
- Used inertia and the elbow method to determine an appropriate number of clusters.  

### Lesson 3: Principal Component Analysis  
- Applied **Principal Component Analysis (PCA)** to reduce the dimensionality of the dataset.  
- Visualized the customer segments in a two-dimensional space.  
- Examined the features that contributed most strongly to the differences between clusters.  

### Lesson 4: Interactive Dashboard  
- Built an interactive dashboard to communicate the segmentation results.  
- Created visualizations that allowed users to compare financial characteristics across clusters.  
- Translated model outputs into understandable customer profiles.  

---

## 🔹 Results  
- Identified distinct household segments with different income, asset, debt, and credit-access profiles.  
- K-Means clustering revealed financial patterns that were not immediately visible during exploratory analysis.  
- PCA reduced the number of dimensions while preserving the most important differences between households.  
- The interactive dashboard made it easier to explore and communicate the characteristics of each customer segment.
