Project 6: Customer Segmentation in the US
🔹 Problem

The goal of this project was to identify meaningful groups of US households based on their financial characteristics. Customer segmentation can help financial institutions understand differences in income, assets, debt, and access to credit, allowing them to design more appropriate financial products and services.

🔹 Approach
Data Preparation
Worked with household financial survey data from the United States.
Selected relevant financial and demographic features for analysis.
Cleaned the data and prepared numerical variables for modelling.
Exploratory Data Analysis
Examined the distributions of household income, assets, debt, and other financial indicators.
Investigated relationships between household characteristics and access to credit.
Used visualisations to identify patterns and differences within the population.
Customer Segmentation
Standardised the selected features to make them comparable.
Applied the K-means clustering algorithm to group households with similar financial characteristics.
Used model diagnostics to select an appropriate number of clusters.
Dimensionality Reduction and Communication
Applied Principal Component Analysis to visualise the clusters in a lower-dimensional space.
Built an interactive dashboard to communicate the characteristics of the customer segments.
🔹 Results
The clustering model identified distinct household segments with different financial profiles.
The segments showed meaningful differences in income, assets, debt levels, and credit access.
Principal Component Analysis helped visualise the separation between the identified groups.
The analysis demonstrated how unsupervised learning can support customer profiling and more targeted financial decision-making.
